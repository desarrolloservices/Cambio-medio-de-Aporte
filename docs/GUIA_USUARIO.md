# Guía de usuario

## Propósito

Este formulario permite actualizar o agregar un medio de aporte para una cuenta AFP. El enlace recibido es personal y tiene una vigencia limitada; no lo comparta con otras personas.

## Antes de iniciar

Tenga disponible lo siguiente:

- El enlace recibido por correo.
- Los datos de la tarjeta, si elegirá ese método.
- La cuenta de ahorro desde la que se realizará el débito, si elegirá ese método.

Si el sistema solicita validación de identidad, complétela antes de continuar con el formulario.

## Registrar un medio de pago

1. Abra el enlace recibido. Espere mientras se valida la sesión y se cargan sus cuentas.
2. En **Selecciona tu cuenta**, elija la cuenta AFP a la que se asociará el aporte.
3. Seleccione **Agregar método de pago** o **Agregar otra tarjeta**, según corresponda.
4. En **Método de pago**, seleccione una de estas opciones:

   - **Tarjeta de crédito o débito**: ingrese el número de tarjeta, la fecha de vencimiento, el banco emisor, el monto del aporte, su frecuencia y el día de débito.
   - **Cuenta de ahorro**: seleccione la cuenta de ahorro que se debitará, el monto, la frecuencia del aporte y el día de débito. No se solicitan datos de tarjeta en esta opción.

5. Seleccione **Mensual** para un aporte recurrente o **Único** para un aporte de una sola vez.
6. Seleccione el día de débito disponible y pulse **Ingresar**.
7. Revise la confirmación y seleccione **Registrar**.

Al finalizar verá un mensaje de éxito y el medio registrado aparecerá en la sección **Tus métodos de pago** cuando el servicio lo confirme.

## Reglas importantes

- Solo se permiten tarjetas Visa o MasterCard válidas.
- La fecha de vencimiento de la tarjeta debe estar vigente.
- Para tarjetas, el monto debe cumplir el mínimo definido para la moneda de la cuenta.
- Si selecciona un día que ya pasó en el mes, el sistema avisará que el débito se realizará el mes siguiente.
- La aplicación no muestra el número completo de la tarjeta en la lista de métodos registrados.

## Administrar métodos ya registrados

En la lista de métodos de pago puede utilizar:

- **Editar** para modificar los datos disponibles del registro.
- **Eliminar** para desactivar el registro después de confirmarlo.

No cierre la página mientras se está procesando un registro, edición o eliminación.

## Problemas frecuentes

| Situación | Qué hacer |
| --- | --- |
| El enlace expiró | Abra nuevamente el enlace original. Si aparece el botón **Solicitar Formulario**, úselo o contacte a soporte. |
| No aparecen cuentas | Actualice la página una vez. Si continúa, use un enlace vigente o contacte a soporte. |
| No se puede registrar la tarjeta | Verifique número, fecha de vencimiento, banco y monto mínimo. |
| No se puede registrar la cuenta de ahorro | Verifique que seleccionó una cuenta y vuelva a intentarlo. |
| Falló la validación de identidad | Complete nuevamente el proceso mostrado en pantalla. |

Para proteger su información, no envíe números completos de tarjetas ni enlaces de acceso por canales no autorizados.
